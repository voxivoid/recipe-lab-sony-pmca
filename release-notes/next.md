New
- The app now notes on the memory card which picture profile was on for your photos, in RECIPLAB/PROFILES.TXT. A photo does not record this itself; Recipe Lab Studio reads the file on import to pick the photo's recipe. It is updated when you leave the app and when the camera powers on.

Please try
- Pick a recipe with a picture profile, leave the app, take a photo, then import it in Recipe Lab Studio and check that it gets that recipe. If it does not, report it on GitHub with your camera model and RECIPLAB/PROFILES.TXT.
