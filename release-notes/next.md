New
- Half-press the shutter on the live view and a box shows where the camera is focusing: amber dashed while it focuses, green when focus locks, an amber double line when focus is uncertain. Let go and it goes. It is never in the photo, and with a manual lens or MF there is simply no box.

Please try
- On an A6000 or any other body, move the focus area off centre (Flexible Spot), half-press in Recipe Lab and check the box sits where the camera's own focus frame does. Then hold MENU → Save a bug report and attach RECIPLAB/REPORT.TXT and a photo of the screen on GitHub, whether it lines up or not.
