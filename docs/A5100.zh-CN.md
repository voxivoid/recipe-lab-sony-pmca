# A5100 操作速查

本版为 A5100 增加触摸式 Fn 入口、MOVIE 键代替 AEL，并默认只显示配方小标签。长按中央键仍为收藏。

「中央键」是背面圆形拨轮中间的按钮；「拨轮」是围着它、可以旋转的圆环。

## 选择并保存

打开「Recipe Lab」→ 转拨轮选配方 → 在配方名称行短按中央键 → 如有画质确认则选择「确认」→ 等保存成功提示 → MENU 退出 → 关机再开机。

「预览中」表示还没保存；「已保存」表示读回的参数一致。还需通过重启后的实拍确认效果保留。

## 显示与配方列表

启动是「仅显示配方小标签」。按MOVIE 键依次切换：小标签 → 完整面板 → 隐藏 → 小标签。

进入完整面板后，用上下键选中配方名称同一行最右侧的「配方列表」，短按中央键打开，作用与原版 Fn 相同。也可直接触摸按钮。在列表内按MOVIE 键或 MENU 返回。

下键选择顺序：配方名称 → 参数栏 → 配方列表 → 配方名称；上键反向。按钮选中后高亮，中央键打开列表，不会保存或收藏当前配方。编辑参数时，上下键仍用于修改数值，先按中央键结束编辑再切换入口。

## 微调参数

先按MOVIE 键切到完整面板。

下键从配方名称切到参数行 → 左右选择参数 → 中央键进入编辑 → 上下或拨轮改数值 → 中央键结束编辑 → 上键回到配方名称行 → 中央键保存。

编辑时转拨轮调整参数；不在编辑状态时转拨轮切换配方，会重置尚未保存的微调。

## 快速选择收藏

在配方名称行长按中央键约 0.6 秒收藏，再长按取消收藏。收藏只是标记，不保存色彩参数。

当前配方已收藏时，点击「配方列表」会直接打开收藏分组；否则打开当前品牌。按左键进入分组列，上下选「收藏」，右键进入右侧配方列，上下或拨轮切换收藏，短按中央键返回主界面预览，再按中央键保存。若停留在参数行，先上下切回配方名称行。

在列表的配方列长按中央键也可以收藏／取消收藏。C1 的开发工具未增加替代入口。

## 恢复标准色彩

按垃圾桶／删除键 → 预览「标准出厂 ST」→ 中央键保存 → MENU 退出 → 关机再开机。

恢复的是应用的标准配方，不是安装前的个性化设置备份。卸载应用不会自动撤销已保存的色彩参数。

| 操作 | 按键 |
|---|---|
| 选配方 | 拨轮或左右 |
| 保存 | 名称行短按中央键 |
| 收藏／取消收藏 | 名称行长按中央键 |
| 返回／退出 | MENU |
| 对焦／拍照 | 半按／全按快门 |
| 恢复标准预览 | 删除键；还需中央键保存 |
